## 4. 异常值识别与事件校验

方法详见 [异常值识别与事件校验](outlier_check.md)，用户口径**只标注不改数**：

1. **多信号识别**（`code/outlier_detect.py`）：对 Δy5/Δy10、ETF 收益、汇率收益、ΔOAS 做滚动/分段 3σ + 绝对下限护栏，产出疑似清单 `outlier_candidates.csv`（132 条）。
2. **事件双向校验**：建立 `events/risk_events_timeline.csv`（2021-08~2026-09，83 条已知宏观/信用事件），逐条把异常日期与事件窗口（±3 日）和 3141.HK 同向性对照。
3. **判定结果** `clean_data/outlier_judgment.csv`（132 条全覆盖）：

| 判定 | 条数 | 处理 |
|---|---|---|
| 真实冲击（有事件支撑，如 2022 CPI/加息、2023 SVB、2025-04 关税、2026 利率波动等） | **116** | 保留 |
| 存疑（无事件支撑、与对照柜台反向） | **16** | 仅标注，不改数；默认规则 = VaR 回测「含/不含」两版对照（见下） |
| 确证下载错误 | **0** | 无修正 |

> **最终 clean 数据零改动**——本阶段无修正项；所有“异常”均为真实市场冲击或在判定表中显式标注，逐条可追溯。
>
> **存疑异常默认处置规则（导师反馈后定稿，阶段二执行）**：16 条「存疑」继续**只标注、不改数**；进入阶段二后 VaR / 回测一律做

## 5. 三大风险因子构建（正式口径 = 官方 NAV 日度）

方法详见 [三大核心风险因子构建与校验](factors.md)（市价口径全流程）与 [报价陈旧出路对照](staleness_remedy.md)（为何改用 NAV）。

### 5.1 因子定义与公式

**正式因子表 `factors/factor_table_nav.csv`**（1273 行 = 1274 − 首行差分），构建脚本 `code/build_factors_nav.py`：

| 列 | 因子 | 定义（NAV 口径） |
|---|---|---|
| `d5y_bp` / `d10y_bp` | 利率因子 | 5Y / 10Y 美债收益率日变化（bp） |
| `fx_ret_pct` | 汇率因子 | CNY/USD 日对数收益 ×100（正 = 人民币贬值） |
| `etf_ret_pct` | 组合收益 | 9141.HK 官方 NAV(USD) 日对数收益 ×100 |
| `etf_rate_attrib_pct` | 利率贡献 | 同日利率剥离回归拟合值（见 5.2） |
| `etf_spread_proxy_pct` | 信用利差代理 | `etf_ret_pct − etf_rate_attrib_pct`（残差） |
| `oas_bp` / `doas_bp` | 外部利差基准 | FRED EM IG OAS 水平 / 日变化（2023-09 起） |

### 5.2 利差剥离（关键口径：NAV 与美股**同日**）

9141.HK 市价在港股先收盘，反映**前一**美股交易日（lag=+1）；而官方 NAV 由基金管理人按美股收盘价估值，**与美股同日（lag=0）**。对照实验证实：NAV 对 Δy 的同日 R²=0.668、隔日仅 0.011。

因此正式拆解为同日回归（`etf_ret_pct` 单位 %，Δy 单位 bp）：

```
ret_nav(t) = α + β5·Δy5(t) + β10·Δy10(t) + ε
   β5 = −0.0085   β10 = −0.0287   α = +0.0015
   R² = 0.668    等效久期 ≈ −(β5+β10)×100 ≈ 3.72 年
```

- `etf_rate_attrib_pct` = 拟合值；`etf_spread_proxy_pct` = 残差 ε。
- **等效久期 3.72 年**与基金实际久期量级一致（> 仅变动日市价法的 3.3y，远好于全样本市价的 1.74y）。
- 外部校验：利差代理与同日 FRED OAS 相关 ρ ≈ −0.18（符号正确；OAS 为 EM 级非紧基准，仅供交叉参考，不作为定值依据）。
- **利差代理的局限（导师反馈后补写，VaR 归因的解释边界）**：
  1. **本质是残差而非可交易利差**——`etf_spread_proxy_pct = etf_ret_pct − etf_rate_attrib_pct`，混有费率 / 估值 / 采样误差与未被利率解释的残差，不是某条真实利差曲线；
  2. **信噪比有限**——日度序列偏“碎”（日 σ 0.164%、超额峰度 +10.5），单日值不可当利差点位用，只宜用于相对变化与尾部事件识别；
  3. **外部交叉弱**——与 FRED EM IG OAS 相关仅 ≈0.18，且 EM 级基准非亚洲/中资紧基准、OAS 指数约 T+1 发布，属“方向校验”而非“数值锚定”；
  4. **在 VaR 中的角色**——只作为「利率剥离后的残差风险」进入因子协方差（靠残差与利率因子正交保证 δ′Σδ 自洽），不声称捕捉真实信用利差敞口。
  故报告中凡出现“利差”之处均指此代理及其局限；若要精确利差敞口需亚洲/中资级 OAS 数据（如 iBoxx Asia、JACI），已列入遗留问题（§8）。

### 5.3 为何「官方 NAV 日度」是正式口径（关键决策）

9141.HK 市价报价陈旧：~63% 相邻真实报价不变、最长横盘 17 天 → 直接喂日度 VaR 会系统性低估波动。三条出路（周度 / 官方 NAV / 真实久期修正）用同一把尺子对照（`factors/staleness_remedy_comparison.csv`）：

| 口径 | 零收益占比 | 年化波动 | 1日99%VaR(正态) | 利率 R² | 等效久期 |
|---|---|---|---|---|---|
| D1 市价日度（原） | 64.7% | 3.66% | 0.536% | 0.23 | 1.74y |
| **D2 官方 NAV 日度** | **6.1%** | **4.52%** | **0.663%** | **0.668** | **3.72y** |
| D3 真久期修正 | 0.7% | 4.30% | 0.630% | — | —（非观测，参考） |
| W1/W2 周度 | 24.9%/0% | 4.30%/4.87% | — | 0.20/0.75 | 2.05y/4.47y（后备） |

**结论：采用 D2。** 市价口径日度 VaR（0.536%）相对 NAV 口径（0.663%）**低估约 24%**。市价表与 3141 表保留作对照，不作阶段二输入。

### 5.4 组合代理选择的两项决策

1. **9141.HK 而非 3141.HK**：3141（HKD 柜台）虽更“活”（陈旧 15% vs 63%），但 ~7.5%/年柜台专属噪声基本无法被利率/利差解释（R² 减半、OAS 校验命中跌至 ~50%≈掷硬币），且含坏报价（2022-04-14 单日 +5.13%）。噪声是“信息污染”，比陈旧更伤因子拆解与日度 VaR。
2. **官方 NAV 而非市价**（本表 §5.3）：市价陈旧属“信息缺失”，用官方 NAV 填补最干净，且与美股同日、时序对齐无相位错位。

### 6.2 金融规律核对结论

1. **收益类一律「尖峰厚尾」**：组合收益超额峰度 +2.06、汇率 +5.36，正态 QQ 图两端明显上翘 → 日度收益显著异于正态，**直接支持阶段二用非正态 / 厚尾敏感的 VaR**（历史模拟优于纯参数正态）。
2. **信用利差代理是全书最“脏”的左尾**：偏度 −1.51、超额峰度 +10.54 → 利差压缩多为小步慢走（>0 占比 56.6%），而**利差骤然走阔呈长左尾**（min −1.04%），正是信用风险最值得计量的方向。组合收益偏度 −0.42 同向印证。
3. **利率贡献偏度 +0.18（轻微右偏）**：样本内含多次**快速宽松**（拟合出来的利率贡献右尾略长），与利差左尾互为对冲——两因子叠加后才得到组合较温和的左偏。这是「组合收益 = 利率 + 利差」双因子框架的直观佐证。
4. **均值量级远小于波动**：日度均值 −0.0092%（≈ 年化 −2.3%）与 σ 0.285% 差两个量级，VaR/风险度量应**以波动（二阶矩）为主**，均值几乎不贡献。水平路径（累计图）显示组合单位净值下跌主要来自样本内利率上行（久期 3.7y），利差贡献累计近零。

>
> **更正（9/14，导师反馈后）**：9141.HK 为**派息型**、样本窗内 20 次除息，除息跳空计入日收益会**系统性高估 σ/VaR**（并非「不受影响」）。
