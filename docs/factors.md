> 对应需求文档「阶段一 · 风险因子拆解」。产出（9141.HK 为正式口径，3141.HK 为对照）：
> `factors/factor_table.csv`、`factors/factor_table_3141HK.csv`、`factors/benchmark_comparison.csv`、
> `figures/spread_factor_vs_oas.png`、`figures/spread_factor_vs_oas_3141HK.png`、脚本 `code/build_factors.py`。

## 一、因子定义

`factor_table.csv`（同一美股交易日对齐，1273 行 = 主日历 1274 − 首行 diff）：

| 列 | 含义 | 口径 |
|---|---|---|
| `d5y_bp` / `d10y_bp` | 利率因子 | 5Y/10Y 美债收益率日变化（bp） |
| `fx_ret_pct` | 汇率因子 | CNY/USD 日对数收益（%），正=人民币贬值 |
| `etf_ret_pct` | 组合收益 | 9141.HK（USD 柜台）Adj Close 日对数收益（%） |
| `etf_rate_attrib_pct` | 利率贡献 | 由 Δy5/Δy10(t-1) 回归拟合的部分（%） |
| `etf_spread_proxy_pct` | 信用利差代理 | `etf_ret_pct − rate_attrib`（残差，%） |
| `oas_bp` / `doas_bp` | 外部利差基准 | FRED EM IG OAS 水平 / 日变化（2023-09 起，之前 NaN） |

## 二、关键时序口径：跨市场时差（lead/lag）

9141.HK 在**港股**收盘定价，时间上早于同日美债收盘 → **今日**基金收益主要由**前一美股交易日**的收益率变动驱动：

- `corr(ETF_t, Δy10_{t-1}) ≈ −0.39`，而同口径 `corr(ETF_t, Δy10_t) ≈ −0.03`（≈0）。
- 利差剥离回归必须使用 **Δy5(t-1)、Δy10(t-1)**（lag=1）；用同期口径回归会几乎无效（R²≈0.00）。

## 三、利差剥离回归（核心）

`etf_ret_pct(t) = α + β5·Δy5(t-1) + β10·Δy10(t-1) + ε`

| 量 | 全样本 | 仅变动日（去陈旧报价） |
|---|---|---|
| 样本 n | 1272 | 449 |
| R² | 0.230 | 0.433 |
| β5 + β10 | −0.0174 | −0.0330 |
| **等效久期 ≈ −(β5+β10)×100** | **1.74 年** | **3.30 年** |

- 利率贡献 `rate_attrib` = 拟合值；信用利差代理 `spread_proxy` = 残差 ε（剔除利率后 = 信用利差驱动 + 噪声）。两收益率高度共线不影响拟合值，故剥离稳健。
- 信号关系：收益率上行 → 价格跌（β<0）；回归样本收益率为“剔除了利差涨跌”的纯利率面，**等效久期是全区间平均**，会被 9141.HK 大量零收益日（陈旧报价）稀释——见下方注意。

## 四、校验：利差代理 vs FRED OAS

重叠窗 2023-09 起，比较 `spread_proxy`（价格，%）与 ΔOAS（bp）。价格与利差**反向**，故预期负相关：

| 口径 | Pearson ρ | 同向命中率 |
|---|---|---|
| 同期 ΔOAS(t) | +0.010 | 39.5% |
| **滞后 ΔOAS(t-1)** | **−0.267** | **63.9%** |

- 滞后口径显著更强：与 II 节时差一致（FRED OAS 亦近 T+1 发布），图与结论采用**滞后一日**口径。
- 该证据表明拆解成立：利差代理确实承载了信用利差信息（ρ 不为 0、符号正确、命中率 >50%），量级 0.2–0.3 属正常（残差中混有大量基金费用/买卖价差/资金流等噪声，非纯利差）。
- 图：`figures/spread_factor_vs_oas.png`（双轴时间序列：利差代理累计 vs OAS 水平 + ΔOAS 散点）。

## 五、9141.HK 报价陈旧 vs 3141.HK（HKD 柜台）噪声 —— 对照实验

**背景**：9141.HK 报价陈旧（真实报价日中 62.7% 相邻报价不变，平均约 2.7 个交易日才更新一次，最长连续不变 17 天）。因怀疑可换更“活”的 HKD 柜台 3141.HK，已用**同一套方法**把 3141 完整跑一遍（新增 `clean_data/benchmark_3141HK_clean.csv`、`factors/factor_table_3141HK.csv`、`figures/spread_factor_vs_oas_3141HK.png`），对照见 `factors/benchmark_comparison.csv`。

### 对照表（同口径全样本）

| 指标 | 9141.HK（USD 柜台） | 3141.HK（HKD 柜台） |
|---|---|---|
| 报价陈旧度（相邻真实报价不变占比） | 62.7% | **15.3%** |
| 最长连续不变（天） | 17 | **5** |
| 平均更新间隔（交易日/次） | 2.68 | **1.18** |
| 组合年化波动（全样本） | 3.66% | 7.40% |
| 利差剥离回归 R²（全样本） | **0.230** | 0.121 |
| 等效久期（全样本） | 1.74 年 | 2.62 年 |
| 仅变动日 R² / n | **0.433** / 449 | 0.141 / 1022 |
| 等效久期（仅变动日） | 3.30 年 | 3.06 年 |
| 利差代理 vs 滞后 ΔOAS：ρ / 命中率 | **−0.267** / **63.9%** | −0.112 / 50.8% |

### 结论

1. **3141 确实更“活”，但多出来的日波动几乎无法被利率/利差解释**：回归 R² 掉一半、利差代理与 OAS 校验近乎失效（命中 50.8%≈掷硬币）。两柜台**同日都变动**的 403 天里，3141 比 9141 平均每天多 ±0.47% 的柜台专属噪声（年化 ≈7.5%）；联系汇率本身每天只动约 0.05%，**该噪声主要来自 HKD 柜台自身报价/撮合质量，不是美元债的真实风险**。
2. **3141 含明显坏报价**：2022-04-14 单日 **+5.13%**（同日 9141 仅 +0.32%）——IG 债基金不可能真涨 5%，属 Yahoo HKD 线坏数据。若换 3141，必须先清这类尖刺，否则 VaR 被单日严重污染。
3. **大事件日两柜台同向一致**（2025-04-10 关税 −1.86%/−1.76%、2022-11-14 中港开放 +1.76%/+1.65%），系统性风险方向上 3141 不提供增量信息。
4. **判定：继续用 9141.HK（USD 柜台）为正式口径。** 用户的直觉（“3141 不是美元”）被数据证实是硬伤——HKD 柜台混入的非美元柜台噪声比 9141 的报价陈旧**更伤**因子拆解与日度 VaR：陈旧是「信息缺失/低频」，可用方法弥补；柜台噪声是「信息污染」，难以清理。仅变动日回归显示两者久期一致（≈3.1 年），9141 的去陈旧估计可信。

### 对阶段二 VaR 的建议（待老师最终拍板）

- 正式输入保留 **9141.HK**；其报价陈旧主要影响**日度**频率——**改周度频率时陈旧问题基本消失**（周度收益不再为零），或使用官方基金 NAV、或按「仅变动日（真实久期 ≈3.3 年）」做口径修正。
- 3141.HK 因子表与对照表**存档备用**，不建议直接作日度 VaR 输入（非美元 + 柜台噪声 + 坏报价）。
- 当前 `factor_table.csv` = 9141.HK 日度口径；仅变动日回归结果作为久期更接近无偏的估计。
