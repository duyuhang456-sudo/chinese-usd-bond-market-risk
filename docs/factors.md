# 三大核心风险因子构建与校验说明（9/10）

> 对应需求文档「阶段一 · 风险因子拆解」。产出：
> `factors/factor_table.csv`、`figures/spread_factor_vs_oas.png`、脚本 `code/build_factors.py`。

## 一、因子定义

`factor_table.csv`（同一美股交易日对齐，1273 行 = 主日历 1274 − 首行 diff）：

| 列 | 含义 | 口径 |
|---|---|---|
| `d5y_bp` / `d10y_bp` | 利率因子 | 5Y/10Y 美债收益率日变化（bp） |
| `fx_ret_pct` | 汇率因子 | CNY/USD 日对数收益（%），正=人民币贬值 |
| `etf_ret_pct` | 组合收益 | 9141.HK（USD 柜台）Adj Close 日对数收益（%） |
| `etf_rate_attrib_pct` | 利率贡献 | 由 Δy5/Δy10(t-1) 回归拟合的部分（%） |
| `etf_spread_proxy_pct` | 信用利差代理 | `etf_ret_pct − rate_attrib`（残差，%） |
| `oas_bp` / `doas_bp` | 外部利差基准 | FRED EM IG OAS 水平 / 日变化（2023-09 起，之前 NaN） |

## 二、关键时序口径：跨市场时差（lead/lag）

9141.HK 在**港股**收盘定价，时间上早于同日美债收盘 → **今日**基金收益主要由**前一美股交易日**的收益率变动驱动：

- `corr(ETF_t, Δy10_{t-1}) ≈ −0.39`，而同口径 `corr(ETF_t, Δy10_t) ≈ −0.03`（≈0）。
- 利差剥离回归必须使用 **Δy5(t-1)、Δy10(t-1)**（lag=1）；用同期口径回归会几乎无效（R²≈0.00）。

## 三、利差剥离回归（核心）

`etf_ret_pct(t) = α + β5·Δy5(t-1) + β10·Δy10(t-1) + ε`

| 量 | 全样本 | 仅变动日（去陈旧报价） |
|---|---|---|
| 样本 n | 1272 | 449 |
| R² | 0.230 | 0.433 |
| β5 + β10 | −0.0174 | −0.0330 |
| **等效久期 ≈ −(β5+β10)×100** | **1.74 年** | **3.30 年** |

- 利率贡献 `rate_attrib` = 拟合值；信用利差代理 `spread_proxy` = 残差 ε（剔除利率后 = 信用利差驱动 + 噪声）。两收益率高度共线不影响拟合值，故剥离稳健。
- 信号关系：收益率上行 → 价格跌（β<0）；回归样本收益率为“剔除了利差涨跌”的纯利率面，**等效久期是全区间平均**，会被 9141.HK 大量零收益日（陈旧报价）稀释——见下方注意。

## 四、校验：利差代理 vs FRED OAS

重叠窗 2023-09 起，比较 `spread_proxy`（价格，%）与 ΔOAS（bp）。价格与利差**反向**，故预期负相关：

| 口径 | Pearson ρ | 同向命中率 |
|---|---|---|
| 同期 ΔOAS(t) | +0.010 | 39.5% |
| **滞后 ΔOAS(t-1)** | **−0.267** | **63.9%** |

- 滞后口径显著更强：与 II 节时差一致（FRED OAS 亦近 T+1 发布），图与结论采用**滞后一日**口径。
- 该证据表明拆解成立：利差代理确实承载了信用利差信息（ρ 不为 0、符号正确、命中率 >50%），量级 0.2–0.3 属正常（残差中混有大量基金费用/买卖价差/资金流等噪声，非纯利差）。
- 图：`figures/spread_factor_vs_oas.png`（双轴时间序列：利差代理累计 vs OAS 水平 + ΔOAS 散点）。

## 五、注意（重要，直接影响阶段二 VaR）

**9141.HK（正式标的）报价陈旧**：1263 个对齐日中 63.4% 为零收益日（更新约每 2.7 个交易日一次；最长连续横盘 16 天）。后果：

1. **全样本回归系数被稀释**（等效久期 1.74 年 ＜ 实际约 3.3 年，R² 0.23），利率/利差拆解的量级会系统性低估久期贡献；
2. **日度 VaR 直接用其日收益会被零收益大量压低**（组合年化波动 3.66%，多数来自少数变动日）；
3. HKD 柜台 **3141.HK 报价明显更活**（零收益占比仅约 16%），或官方 NAV 更佳。

→ 阶段二需由指导老师拍板口径，候选：(a) 换 3141.HK；(b) 改周度频率；(c) 用官方基金 NAV；(d) 继续 9141 但在日度 VaR 里做去陈旧（仅变动日）修正。当前 `factor_table.csv` 保留 9141.HK 日度口径，仅变动日回归结果作为久期更接近无偏的估计写入本说明。
