## 3. 因子暴露设定 δ（参数法方差-协方差用）

组合日收益与三因子的同日线性关系，估计在**复权主口径收益** `etf_ret_tr_pct` 上重做（阶段一同日剥离方法不变）：

```
ret_tr(t) ≈ β5·Δ5Y(t) + β10·Δ10Y(t) + 1·spread_proxy_tr(t)
```

| 因子 | 序列（源列） | 暴露 δ | 含义 | 说明 |
|---|---|---|---|---|
| 利率 Δ5Y | `d5y_bp` (bp) | **β5 = −0.0077** | %收益/bp | 与 Δ10Y 高度共线（ρ≈0.94），协方差法已吸收 |
| 利率 Δ10Y | `d10y_bp` (bp) | **β10 = −0.0293** | %收益/bp | 等效久期 ≈ −(β5+β10)×100 ≈ **3.70y** |
| 信用利差 | `etf_spread_proxy_tr_pct` (%) | **1.0** | %收益/%残差 | OLS 残差，与两利率因子正交（ρ=0） |
| 汇率 CNY/USD | `fx_ret_pct` (%) | **0.0** | — | USD 本位；人民币次口径（δ=+1）才计入 |

**自洽校验（9/14 实测）**：用三因子协方差 Σ 算 √(δ′Σδ) = **0.2660 %/日**，与复权收益经验 σ = **0.2660 %/日**几乎完全一致
（差 < 0.0001 个百分点）——即组合方差可由「利率 + 利差代理」两族因子完全解释，汇率无信息增量（再次支持主口径 δ_fx=0）。
因子协方差/相关系数：`results/factor_corr.csv`、`results/factor_exposure.csv`。

**双口径设计（依据导师反馈追加）**：上表 = **USD 主口径**（VaR 上报），汇率暴露 = 0，对标持仓自身的市场风险；
另设**人民币视角次口径**——人民币投资者总收益 `ret_rmb ≈ ret_usd_tr + fx_ret`（精确为 (1+r)(1+fx)−1），暴露 = 主口径 δ **叠加汇率暴露 +1**，
让「利率 + 信用 + 汇率」三类风险进入同一总收益框架、可做全维度压力测试（衔接第 3 周）。两口径的 VaR 序列都会产出（9/15~16），上报以主口径为准、次口径作对照。
（按本口径，把 CNY/USD 因子暴露「直接置零不纳入任何 VaR」的做法不再成立——主口径置零、次口径纳入，分而治之。）

**信用利差代理的局限（VaR 归因的解释边界）**：`etf_spread_proxy_pct` 是「组合收益扣利率后残差」，非独立可交易利差序列——
信噪比有限（日 σ 0.164%），与外部 EM IG OAS 同日相关仅 ≈0.18（符号对、量级一般），且 EM 级基准非亚洲/中资紧基准、OAS 指数约 T+1 发布。
因此 VaR 中该因子的贡献宜解读为「利差/残差风险」而非精确利差敞口；δ_normal 的自洽性依赖残差正交性（√(δ′Σδ)≈经验 σ 即证据），
不把「利差代理」当作可独立对冲的真实利差。详见 `docs/factors.md` 局限节。

## 4. 参数法 VaR（方差-协方差 + GARCH(1,1) 修正）

实现两种参数化（9/15 落地 `code/var_parametric.py`）：

- **M1 · 方差-协方差（delta-normal）**：在滚动估计窗内估计三因子协方差 Σ_w，组合 σ_p = √(δ′Σ_w δ)（δ 固定为 §3），
  逐窗前推得样本外 `VaR_c = z_c·σ_p`（z₉₅=1.6449，z₉₉=2.3263，μ=0）。
- **M1g · GARCH(1,1) 修正（推荐主口径之一）**：对复权主口径收益在扩展窗拟合 `arch` 的 GARCH(1,1)（先正态、后 Student-t 对照），
  得逐日条件 σ_t → `VaR_c(t) = z_c·σ_t`。σ_t 能捕捉波动聚集（2022/2025-04 段 σ_t 抬升），是对 delta-normal「窗内恒定 σ」的改进。

> 按需求文档表述，M1g 是对 M1 的波动率修正；两者都算、回测见高下（§7）。

## 6. 历史模拟法 VaR

- **M2 · 经典 HS**：对过去 **250 个交易日** 复权主口径收益取经验分位——`VaR_c = −quantile(r_win, 1−c)`（e.g. 99% → −r 的 1% 分位，损失取正）。滚动步长 1 日，逐日样本外前推。
- **M2f · Filtered-HS（对照）**：窗内历史收益除以窗内 σ̂ 再乘当日条件 σ_t（用 M1g 的 GARCH σ_t），改善高波动期 HS 的响应滞后。
- **窗宽稳健性（9/16）**：250 / 500 / 750，检查 99% 分位是否收敛（阶段一教训：周度仅 265 观测、99% 分位不稳；NAV 日度 1273 观测应明显更稳）。
- 产出：`results/var_historical.csv`（含各窗对照）。

## 7. 回测协议（9/17 统一执行）

### 7.1 结构

| 项 | 设定 |
|---|---|
| 估计窗 | **250 交易日**（与需求文档一致），滚动步长 **1 日** |
| 样本外起点 | 数据第 251 个收益日（估计窗满）起；NAV 收益共 1273 → 样本外 **1023 个预测日**（约 2022-08 ~ 2026-09） |
| 违规判定 | 第 t 日用 `[t−250, t−1]`（或 GARCH 扩展到 t−1）预测 VaR_t；若**实际收益 r_t < −VaR_t**（损失超 VaR）记 1 次违规 |
| 期望违规数 | 名义独立下：95% → ≈51 次、99% → ≈10 次（1023 日） |

### 7.2 统计检验

1. **失败率（无条件覆盖）**：`x/N` vs 名义 p=1−c，应接近 5%/1%。
2. **Kupiec 似然比（LR_uc，必做）**：
   `LR_uc = −2·ln[ (1−p)^{N−x}·p^x / (1−x/N)^{N−x}·(x/N)^x ] ~ χ²(1)`；p 值 <5% 拒绝（覆盖不足或过度）。
3. **Christoffersen 独立性（LR_ind，必做，与 LR_uc 并列）**：检验违规是否聚集（run 检验，~ χ²(1)）。
   两问合一：**整体覆盖率准不准（LR_uc）+ 违规会不会扎堆（LR_ind）**。违规聚集比单纯失败率偏高更严重——LR_ind 显著说明 VaR 未及时跟上波动聚集
   （条件覆盖失效，应倾向 GARCH/Filtered-HS 类条件化模型）。LR_uc 与 LR_ind 合成为条件覆盖 LR_cc 一并给出。
4. 附期望超损（ES/1−c 平均损失）作参照，衡量超 VaR 的深度。

> 预研级样本（99% 下 ~10 次期望违规）检验力有限——结论以「点估计 + 区间 + 分段一致性」给，不单纯依赖拒绝/不拒绝。

### 7.3 分段评估（平稳 vs 高波动）

分段表 `results/regimes.csv`（9/14 产出，逐日）：
- **慢性高波动态**：60 交易日滚动年化实现波动 ≥ 全样本上 2/3 分位（阈值 **4.54%**）→ **405 天（32%）**，集中于 2022–25（按年 209/159/27/10 天）。
- **急性危机窗（叠加）**：事件时间线 ± 内若 |复权日收益| ≥ **1.2%（≈4.5σ）** 记危机窗。9/14 实测仅 2022-06 CPI/FOMC 两窗达标（2022-06-06~06-22 共 12 天，均在慢性段内）；
  复权单日最大 |1.34%|，故 2025-04 关税的 −1.86%（市价口径）在 NAV 上未达单日线——**注意**：事件冲击在 NAV 上往往摊到多日，后续用“事件窗累计收益”复核。
- 分段指标：两模型 × 两置信度在每段的失败率、**Kupiec LR_uc + Christoffersen LR_ind（两问都给）**、平均 VaR、期望超损；
  回答“谁在高波动段更稳、谁在平稳段更省资本、谁的违规在段内聚集”。

## 8. 稳健性 / 特殊处理规则

1. **16 条「存疑」异常日（阶段一，只标注不改数）——默认处置规则定稿**：`results/doubtful_days.csv`（11 ETF/3 dOAS/2 FX，均为**市价口径**识别）。
   默认规则（依据导师反馈定稿）：延续「只标注不改数」；**回测一律做「含/不含」两版对照**（必做，不作可选项）；任一违规日若落入存疑清单，
   先核 3141 同向性与事件时间线再归因，结论不以个别存疑日为准。注意其中 ETF 日为市价异常，映射到 NAV 收益可能不同——逐条核对。
2. **分红除权 → 复权（总收益）输入（依据导师反馈，9/14 已落地定稿）**：不再用除权 NAV 直接算收益（除息跳空会系统性高估 σ）。
   正式输入 = **加回分红后的复权日收益**（USD 主口径 `etf_ret_tr_pct`，源 `factors/factor_table_nav_tr.csv`；
   分红记录 = 基金官方派息公告，`raw_data/dividends_9141HK.csv`，样本窗内 20/20 期除息命中并核对）。
   **实测量化**：σ_ann 4.52%→4.22%、1 日 99% VaR 0.663%→0.619%（除息跳空高估约 6%）；人民币次口径 `etf_ret_rmb_pct`
   （1268 行）同表落地。复权后除息日机械跳空从输入中消除，本项由「伪违规识别」降级为「复权边界核验」：个别无官方记录的除息日仍可能在收益上留痕，
   若违规日落在疑似除息日，标注区分即可，不删除、不因单点改写结论。
3. **GARCH 稳健性**：若 α+β≈1 或收敛异常，退 EWMA(λ=0.94)/Student-t 对照并如实报告。
4. **可复现**：脚本从 `factor_table_nav_tr.csv` 一键重跑；随机数固定（arch 正态无需 seed，Student-t 亦确定）；CSV 均 utf-8-sig；日期按主日历对齐。
