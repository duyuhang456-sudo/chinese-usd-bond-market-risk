## 3. 因子暴露设定 δ（参数法方差-协方差用）

组合日收益与因子同日线性关系（阶段一 NAV 同日剥离定案）：

```
ret_NAV(t) ≈ β5·Δ5Y(t) + β10·Δ10Y(t) + 1·spread_proxy(t)
```

| 因子 | 序列（源列） | 暴露 δ | 含义 | 说明 |
|---|---|---|---|---|
| 利率 Δ5Y | `d5y_bp` (bp) | **β5 = −0.008503** | %收益/bp | 与 Δ10Y 高度共线（ρ≈0.94），协方差法已吸收 |
| 利率 Δ10Y | `d10y_bp` (bp) | **β10 = −0.028679** | %收益/bp | 等效久期 ≈ −(β5+β10)×100 ≈ **3.72y** |
| 信用利差 | `etf_spread_proxy_pct` (%) | **1.0** | %收益/%残差 | OLS 残差，与两利率因子正交（ρ=0） |
| 汇率 CNY/USD | `fx_ret_pct` (%) | **0.0** | — | USD 本位；仅人民币折算回报才需计入 |

**自洽校验（9/14 实测）**：用三因子协方差 Σ 算 √(δ′Σδ) = **0.2849 %/日**，与 NAV 收益经验 σ = **0.2849 %/日**几乎完全一致
（差 < 0.0001 个百分点）——即 NAV 方差可由「利率 + 利差代理」两族因子完全解释，汇率无信息增量（再次支持 δ_fx=0）。
因子协方差/相关系数：`results/factor_corr.csv`、`results/factor_exposure.csv`。

## 4. 参数法 VaR（方差-协方差 + GARCH(1,1) 修正）

实现两种参数化（9/15 落地 `code/var_parametric.py`）：

- **M1 · 方差-协方差（delta-normal）**：在滚动估计窗内估计三因子协方差 Σ_w，组合 σ_p = √(δ′Σ_w δ)（δ 固定为 §3），
  逐窗前推得样本外 `VaR_c = z_c·σ_p`（z₉₅=1.6449，z₉₉=2.3263，μ=0）。
- **M1g · GARCH(1,1) 修正（推荐主口径之一）**：对 NAV 日收益在扩展窗拟合 `arch` 的 GARCH(1,1)（先正态、后 Student-t 对照），
  得逐日条件 σ_t → `VaR_c(t) = z_c·σ_t`。σ_t 能捕捉波动聚集（2022/2025-04 段 σ_t 抬升），是对 delta-normal「窗内恒定 σ」的改进。

> 按需求文档表述，M1g 是对 M1 的波动率修正；两者都算、回测见高下（§7）。

## 5. 基线 VaR（无条件正态，9/14 实测）

| 置信度 | z | VaR（μ=0，%） | VaR（含 μ，%） |
|---|---|---|---|
| 95% | 1.6449 | **0.4686** | 0.4777 |
| 99% | 2.3263 | **0.6627** | 0.6718 |

- 与阶段一 1 日 99% VaR(normal) 0.663% 交叉核对一致（同一 σ=0.285%/日、σ_ann=4.52%）。
- **口径警示**：若用 9141.HK 市价日度（报价陈旧）σ_ann=3.66%、VaR 99% = 0.536%，比 NAV 口径**低估约 24%**——即为什么 VaR 一律用 NAV。
- 因收益尖峰厚尾，预期**历史模拟 99% VaR > 正态 0.663%**、且 GARCH 在高波动段显著抬升——这将成为 9/17 对比的核心看点。
- 产出：`results/baseline_var.csv`。

## 6. 历史模拟法 VaR

- **M2 · 经典 HS**：对过去 **250 个交易日** NAV 收益取经验分位——`VaR_c = −quantile(r_win, 1−c)`（e.g. 99% → −r 的 1% 分位，损失取正）。滚动步长 1 日，逐日样本外前推。
- **M2f · Filtered-HS（对照）**：窗内历史收益除以窗内 σ̂ 再乘当日条件 σ_t（用 M1g 的 GARCH σ_t），改善高波动期 HS 的响应滞后。
- **窗宽稳健性（9/16）**：250 / 500 / 750，检查 99% 分位是否收敛（阶段一教训：周度仅 265 观测、99% 分位不稳；NAV 日度 1273 观测应明显更稳）。
- 产出：`results/var_historical.csv`（含各窗对照）。

## 7. 回测协议（9/17 统一执行）

### 7.1 结构

| 项 | 设定 |
|---|---|
| 估计窗 | **250 交易日**（与需求文档一致），滚动步长 **1 日** |
| 样本外起点 | 数据第 251 个收益日（估计窗满）起；NAV 收益共 1273 → 样本外 **1023 个预测日**（约 2022-08 ~ 2026-09） |
| 违规判定 | 第 t 日用 `[t−250, t−1]`（或 GARCH 扩展到 t−1）预测 VaR_t；若**实际收益 r_t < −VaR_t**（损失超 VaR）记 1 次违规 |
| 期望违规数 | 名义独立下：95% → ≈51 次、99% → ≈10 次（1023 日） |

### 7.2 统计检验

1. **失败率（无条件覆盖）**：`x/N` vs 名义 p=1−c，应接近 5%/1%。
2. **Kupiec 似然比（LR_uc，核心）**：
   `LR_uc = −2·ln[ (1−p)^{N−x}·p^x / (1−x/N)^{N−x}·(x/N)^x ] ~ χ²(1)`；p 值 <5% 拒绝（覆盖不足或过度）。
3. **Christoffersen 独立性（加分项）**：违规是否聚集（LR_ind，run 检验）；与 LR_uc 合成为条件覆盖 LR_cc。
4. 附期望超损（ES/1−c 平均损失）作参照，衡量超 VaR 的深度。

> 预研级样本（99% 下 ~10 次期望违规）检验力有限——结论以「点估计 + 区间 + 分段一致性」给，不单纯依赖拒绝/不拒绝。

### 7.3 分段评估（平稳 vs 高波动）

分段表 `results/regimes.csv`（9/14 产出，逐日）：
- **慢性高波动态**：60 交易日滚动年化实现波动 ≥ 全样本上 2/3 分位（阈值 **4.87%**）→ **405 天（32%）**，集中于 2022–23（209+166 天）。
- **急性危机窗（叠加）**：事件时间线 ± 内若 |NAV 日收益| ≥ **1.2%（≈4σ）** 记危机窗。9/14 实测仅 2022-06 CPI/FOMC 两窗达标（2022-06-06~06-22 共 12 天，均在慢性段内）；
  NAV 单日最大 |1.34%|，故 2025-04 关税的 −1.86%（市价口径）在 NAV 上未达单日线——**注意**：事件冲击在 NAV 上往往摊到多日，后续用“事件窗累计收益”复核。
- 分段指标：两模型 × 两置信度在每段的失败率、平均 VaR、期望超损；回答“谁在高波动段更稳、谁在平稳段更省资本”。

## 8. 稳健性 / 特殊处理规则

1. **16 条「存疑」异常日（阶段一，只标注不改数）**：`results/doubtful_days.csv`（11 ETF/3 dOAS/2 FX，均为**市价口径**识别）。
   9/17 做法：不修数；检查这些日期是否落入 NAV VaR 违规，做「含/不含」两版回测，确认结论不对单日敏感。
   注意其中 ETF 日为市价异常，映射到 NAV 收益可能不同——逐条核对。
2. **NAV 除权（分红除息）伪违规**：NAV 为每单位净值，除息日含既定小跳。9/17 若违规日与疑似除息日重合，单独标注区分「真市场冲击」与「机械跳空」，不删除、不因单点改写结论。
3. **GARCH 稳健性**：若 α+β≈1 或收敛异常，退 EWMA(λ=0.94)/Student-t 对照并如实报告。
4. **可复现**：脚本从 `factor_table_nav.csv` 一键重跑；随机数固定（arch 正态无需 seed，Student-t 亦确定）；CSV 均 utf-8-sig；日期按主日历对齐。
