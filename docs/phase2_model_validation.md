# 模型验证分析报告（阶段二 · 风险计量模型开发与回测验证）

**范围**：中资投资级美元债组合代理（华夏亚洲美元投资级债券 ETF，9141.HK / USD 柜台）的日度 VaR 计量，
2026-09-14 ~ 09-18。**口径与协议**见《[VaR 计量口径与回测协议](phase2_spec.md)》（下称 spec），
本报告只呈现验证结果与由此得出的适用性判断，不新增口径。

**结论一句话**：日度 95%/99% VaR 在本样本上**没有出现风险低估**；所有被拒绝的配置都是**过度覆盖**
（VaR 偏高、资本浪费）。同时样本证据不支持"条件化模型（GARCH / Filtered-HS）在本资产上优于无条件模型"——
**复杂化没有换来可验证的增益**（见 §七）。

**交付物**：
`results/var_parametric.csv`、`results/var_historical.csv`、`results/backtest_results.csv`（262 行 × 33 列）、
`results/backtest_exceptions.csv`（832 行）；图 `figures/var_*.png`、`figures/backtest_exceptions.png`、`figures/backtest_coverage.png`。

## 二、VaR 计量口径

### 2.1 双口径并行

| 口径 | 收益列 | 定义 | 样本 | σ_日 | σ_年化 | 1 日 95% VaR | 1 日 99% VaR |
|---|---|---|---|---|---|---|---|
| **主口径（USD 复权）** | `etf_ret_tr_pct` | 加回分红的 USD 总收益 | 1273 | 0.2660% | 4.223% | 0.4376% | 0.6189% |
| **次口径（人民币）** | `etf_ret_rmb_pct` | 人民币视角总收益（含汇率折算） | 1268 | 0.3221% | 5.113% | 0.5298% | 0.7493% |
| 除权 USD（审计底，不用） | `etf_ret_pct` | 未加回分红 | 1273 | 0.2849% | 4.522% | 0.4686% | 0.6627% |

**为什么必须双口径**：次口径 99% VaR 平均比主口径高，**比值 1.239**；归因表（`results/var_attribution.csv`）
给出汇率成分贡献 **44.2%** 的方差，与利率成分（45.7%）几乎等权。两者不是同一风险的两种表述，
而是**两个不同的风险来源**——本样本上有一条违规**只存在于次口径**（2025-01-21：主口径当日为正收益 +0.2349%，
次口径 r = −0.5009% 且 fx = −0.7358%，是**纯汇率折算损失**，主口径完全看不到）。故次口径**不替代**主口径，
而是并行披露。

**为什么用复权**：9141.HK 为派息型，样本窗内 20 次除息。除息跳空计入日收益会**系统性高估** σ 与 VaR
（σ_年化 4.52% → 4.22%，1 日 99% VaR 0.663% → 0.619%，约 6%）。正式输入一律用复权表，
除权表仅作审计底（spec §8.2）。

### 2.2 一个必须声明的分母口径

主口径样本外有 **64/1023 日（6.26%）复权收益恰为 0.0000%**，这些日子**机械上不可能违规**
（`0 < −VaR` 恒不成立）。故期望违规数分两口径：**含零收益日** 95% 51.2 / 99% 10.2，
**剔除后** 95% **48.0** / 99% **9.6**。`backtest_results.csv` 并列 `exp_x` 与 `exp_x_eff` 两列，
**本报告统一用 `exp_x_eff`**。

## 三、模型实现

### 3.1 参数法（`code/var_parametric.py`）

| 模型 | 设定 |
|---|---|
| **M1** | 滚动 250 日无条件 σ，δ-normal（正态分位） |
| **M1g** | 扩展窗逐日重估 GARCH(1,1)-正态，条件 σ_t |
| **M1e** | EWMA(λ=0.94) 条件 σ，回退 |
| **M1g-t** | **对照**：t 似然估 σ、仍配正态分位（见 §3.3 披露） |
| **M1δ** | δ-normal 的因子暴露形式（见 §3.3 恒等式披露） |

GARCH 稳健性：主口径 α+β = 0.9960、次口径 0.9968（近 IGARCH）；**次口径有 133/1268 次重估落到
α→0、β→1 的边界解**（2022-08-03 ~ 2023-04-10，人民币贬值高波动段），该段 σ_t 退化为常数；
主口径 0 次边界解。逐日落痕于 `results/garch_refit_trace_{main,rmb}.csv`。

### 3.2 历史模拟法（`code/var_historical.py`）

| 模型 | 设定 |
|---|---|
| **HS250 / HS500 / HS750** | 经典历史模拟，窗宽 250 / 500 / 750 |
| **FHS-E** | Filtered-HS，EWMA(λ=0.94) 滤波 |
| **FHS-G** | Filtered-HS，GARCH(1,1) 滤波 |

滤波版一律用**成熟种子**（即从第 251 日起算）、少 250 日如实记档不补齐：用序列首日播种的 EWMA
会因首日种子与真实方差差 53 倍而把 1% z 分位抬高约 85%（spec §7.1）。FHS 有效样本为 773 日。

### 3.3 两条防止误读的披露

1. **M1δ ≡ M1 是代数恒等式，不构成独立模型证据。** 因利差代理因子被定义为同一次 OLS 的残差，
   任意窗口上 `δ′Σ_wδ ≡ var_w(r)`（实测 σ 最大差 4.4e−06，违规日集合逐一相同）。它的价值只在
   **归因与压力映射**，`role` 列已标「恒等式」，两张图与本节对比均不将其计入独立模型。
2. **M1g-t 不是 t 分布 VaR。** 实测 `garch_t_var_{95,99} / sig_garch_t ≡ 1.6449 / 2.3263`，
   即**用 t 似然估计 σ、仍配正态分位**。`var_parametric.py` 未改动（改动会破坏 md5 基线），
   在此如实披露以免被读成厚尾模型。

## 四、回测框架与统计检验

### 4.1 三个检验

| 检验 | 统计量 | 回答的问题 | 自由度 |
|---|---|---|---|
| 失败率 | x / N | 覆盖率点估计 | — |
| **Kupiec LR_uc** | 似然比 | 覆盖率**整体**准不准 | χ²(1) |
| **Christoffersen LR_ind** | 转移计数似然比 | 违规会不会**扎堆**（聚集 = 条件覆盖失效） | χ²(1) |
| LR_cc | LR_uc + LR_ind | 两问联合 | χ²(2) |

转移计数按 `hits[:-1] → hits[1:]` 统计 n00/n01/n10/n11，`π̂01`/`π̂11` 分母为 0 时对应项系数为 0。
所有检验层在 `code/var_common.py`，与 9/15、9/16 的违规判定**共用同一个 `hit_series`**，不存在口径分叉。

### 4.2 检验力必须实测，不能假设

χ²(1) 是渐近近似。用蒙特卡洛（iid Bernoulli，B=20000，固定种子）实测**名义水平对应的真实拒绝率**：

| N | p | LR_uc 实际 | **LR_ind 实际** | 方向 |
|---|---|---|---|---|
| 1023 | 0.05 | 5.49% | **7.73%** | 偏宽松 |
| 773 | 0.05 | 4.97% | **7.12%** | 偏宽松 |
| 523 | 0.05 | 4.57% | 3.87% | 略保守 |
| 299（高波动段） | 0.05 | 6.39% | 2.16% | 保守 |
| 1023 | 0.01 | 4.10% | **1.56%** | 保守 |
| 773 | 0.01 | 4.33% | 1.85% | 保守 |
| 523 | 0.01 | 5.17% | 1.39% | 保守 |
| 299 | 0.01 | 8.32% | **1.29%** | 保守 |
| 133（次口径边界解段） | 0.01 | 1.17% | 0.82% | 保守 |

**读法**（这是本报告后续所有检验结论的前提）：

- **95% 口径下 LR_ind 偏宽松**（名义 5% 实际约 7~8%）→ 该口径下 p < 0.05 的"显著"要打折；
- **99% 口径下 LR_ind 偏保守**（实际仅约 1.3~1.9%）→ **不显著是检验力不足的弱结论，不等于"证明无聚集"**；
- **高波动段（N=299）几乎不具备检验力**（实际水平 1.29%）→ 该段只能作描述性对比。

为此 `backtest_results.csv` 除 χ² 的 `p_ind` 外并列给出**条件蒙特卡洛 p 值 `p_ind_mc_cond`**
（按**观测到的违规数 x** 模拟 iid Bernoulli(x/N)，B=20000，固定种子）。注意它**不是单调放大 p**——
在观测违规数低于期望时反而更小。**报告以 `p_ind_mc_cond` 为准，χ² p 作对照。**

### 4.3 多重比较

同时对多个配置做检验，假阳性会累积。三种族定义下的 Bonferroni 门槛：

| 族 | 检验次数 | 门槛 |
|---|---|---|
| 主比较集（8 主模型 × 2 置信度 × 2 口径） | **32** | 0.05/32 = **0.00156** |
| 加两个对照模型（10 变体，减 M1g-t 无次口径的 2 行） | 38 | 0.00132 |
| 全表（含各分段与含/不含 scope） | **262** | 0.05/262 = **0.00019** |

1. **高波动段平均 VaR 普遍抬升**，次口径幅度更大（M1 99%：0.6592% → 0.9744%，+48%）。
2. **超损倍数的分段变化在两个口径上方向相反**：次口径高波动段普遍**上升**（M1 95% 1.26 → 1.46、
   HS250 1.30 → 1.47、M1g 1.27 → 1.40），而主口径同期**下降**（M1 95% 1.28 → 1.17）。
   即**高波动段尾部深度的增量主要由汇率成分贡献**，与归因表（汇率 44.2%）口径一致。
3. 高波动段 99% 下 HS500 与 FHS-E/G 的违规数为 **0/88**，ES 与超损倍数无法计算，记 NaN——
   这是样本量问题，不构成"这些模型在高波动段最安全"的证据。

## 七、模型对比与适用性结论

### 7.1 四个对比问题

**① GARCH 条件化是否消除了违规聚集？**
**不能宣称"消除"，也不能宣称"存在聚集"。** 主口径下 M1 与 M1g 的 LR_ind 分别为 0.038 与 0.016，
两者之差**远小于各自的水平失真**（95% 下名义 5% 实际约 7~8%）；99% 下检验力更弱（实际约 1.6%），
**不显著是弱结论**。全表 262 行中有 11 行名义显著，规律很整齐：
次口径 HS500 95% 的六种 scope（n01≈20 / n10≈21 / **n11 = 3**）、主口径高波动段的几个小样本行（x 仅 2~6 次）；
**11 行全部落在 95%、无一落在 99%**。而它们**六种 scope 高度重叠、并非六次独立发现**，
在 32 次、38 次或 262 次三种多重比较口径下**均不成立**（全局最小 p = 0.00735，门槛 0.00019）。
→ **本样本不足以分辨条件化模型与无条件模型在聚集性上的差异。这是检验力问题，不是模型优劣的证据。**

**② 历史模拟与参数法在极端日谁先反应？**
对 6 个最差 |r| 日，读各模型当日 VaR 在其自身前 250 日 VaR 分布中的分位（分位低 = 当天尚未抬升 VaR）：

- 2025-04-07（−1.1491%，8/8 模型在 99% 上违规，分位中位数 19）与 2023-10-03（4/4 违规，分位中位数 0）
  的低分位是 **ghost effect 的机械结果**——这两日分别是登记跳变点 2025-04-08、2023-10-04 的**前一交易日**，
  大额亏损次日才进入窗口，**不可读作"模型没反应"**。
- **唯一干净的是 2023-02-21**：M1 已在 68 分位（提前抬升），而 M1g 降到 2 分位、M1e 降到 1 分位并在 99% 上违规
  ——**条件化模型当日反而把 VaR 压低了**。
- 另 3 日（2022-08-05、2022-09-22、2022-09-26）落在样本外前 38 日内，各模型 VaR 历史不足 250 日，无可用分位。

样本仅此一日，**只作现象记录，不足以下结论**。

**③ 双口径 VaR 的量级差能否归因？**
能，且有两处独立佐证。次口径 99% VaR 平均比主口径高（比值 1.239），归因表给汇率贡献 44.2%；
本次用违规数作独立佐证：次口径 M1 在 95% 上比主口径更准（4.03% vs 2.83%，主口径被拒而次口径不拒）。
两处方向一致 → **汇率成分是次口径 VaR 抬升的主因，且它同时降低了收益自相关**。

**④ 次口径 GARCH 边界解段（2022-08-03 ~ 2023-04-10，133 天）能否作为条件化优势的证据？**
**不能。** 该段 rmb GARCH 99% 违规 0/133、rmb M1 99% 违规 3/133，n 太小；且该段恰是次口径高波动段的一部分，
而该段 LR_uc 实测水平仅 1.17%、LR_ind 仅 0.82%——**检验在该段几乎不拒绝任何东西**。
任何"次口径 GARCH 在高波动段更优"的说法都不得引用这段（spec §4、§8.3）。

### 7.2 基准口径定案（供阶段三压力测试对标）

**定案结论：主口径与次口径、95% 与 99% 四个配置，统一采用 HS250 一个模型。**

四个配置共用同一版本，是「把基准模型定死」的字面落实——若 95% 用一版、99% 用另一版，
两档损失就不可比，基准等于没有定死。

**判定规则**（写在 `code/recommend_baseline.py`，先写死再跑数，避免事后挑标准）：

1. **基准样本**：跨模型横比一律在 `common773` 上做（主口径 773 日 / 次口径 768 日，2023-08-03 起）。
   `full` 范围下各模型样本长度不同（HS250 有 1023 日、FHS 类只有 773 日），而 2022-08~2023-08
   恰是波动最高的时段，直接比平均 VaR 会把样本构成差异误读成模型差异（§5.3 已立此规矩）。
2. **门槛一（通过率，硬）**：可达的核心范围（`full`/`common773`/`common523`/`calm`/`highvol`）
   上 Kupiec 全部不拒绝。
3. **门槛二（审慎，硬）**：①无**显著**风险低估（须 Kupiec 拒绝且方向为 x > 期望，x 偶然偏大不算）；
   ②基准样本失败率相对名义偏离 ≤ +10%（过度覆盖方向不设限）；③①②须在 95% 与 99% **两档同时满足**。
   第 ③ 条同时筛掉了「95% 勉强合格、99% 大幅低估」的滤波类模型——它们 95% 的合格只是 99% 失守的较轻表现。
4. **排序（准确优先于节约）**：两档校准偏差均值 `mean(|rate/名义 − 1|)` 升序。
   基准口径的本职是当参照物，第一要求是准，其次才是省；**资本占用不作否决门槛**，
   仅作并列裁决条件（两档校准偏差相差 < 10% 时取资本占用更低者）。
5. **稳定性否决**：条件覆盖落差 > 2.0pp，**且仅在该模型高波动段 T ≥ 250 时启用**
   （HS500/FHS 该段仅 88 日，落差不可测，不由不可测的数字否决模型）；

### 7.3 因子冲击到组合损失的线性传导精度（进入压力测试前的前置验证）

**为什么必须先做这一步**：阶段三压力测试的全部损失估计都建立在「δ × 因子冲击」这条线性链上，
链条本身的误差必须先量出来，否则无法判断情景损失里哪一部分是市场冲击、哪一部分是模型误差。

**第一步：先确认 δ 是什么。** `results/factor_exposure.csv` 报出的 δ 向量混合了两类性质不同的对象：

| 因子 | δ 值 | 性质 |
|---|---:|---|
| 利率 Δ5Y | −0.007714 %/bp | 同日 OLS 估计的**真实暴露**，可观测、可外推 |
| 利率 Δ10Y | −0.029303 %/bp | 同上（两式合计等效久期约 3.70 年） |
| 信用利差代理 | +1.000 | **回归残差本身**（`build_tr_factors.py` L96：`etf_spread_proxy_tr_pct = etf_ret_tr_pct − etf_rate_attrib_tr_pct`），不是估计结果 |
| 汇率 CNY/USD | 0.000 | 主口径 USD 本位的**口径设定**，不是估计结果 |

第三项 δ ≡ 1 意味着 `r ≡ c + δ5·Δ5Y + δ10·Δ10Y + 1.0×残差` 在估计样本上是**代数恒等式**。
实测 `max|估算 − 实际| = 8.79e−5 pp`（数值误差量级，R²≡1）——**用残差当因子去「验证传导精度」
是循环论证，必然得到零偏差的假结论**。该配置在 9/17 回测中已登记为 M1δ（role = 恒等式，
禁止作独立证据），此处再次确认其不可用于本项验证。

可观测的利率双因子子模型 R² = 0.7568（n=1273）：**可观测因子解释 75.7% 的组合收益方差，
剩余 24.3% 落在没有 δ 可用的信用维度上**。故检验对象定为：

| 模型 | 形式 | 用途 |
|---|---|---|
| **M2 利率双因子** | `r̂ = c + δ5·Δ5Y + δ10·Δ10Y` | 现状口径，**主检验对象** |
| M3 利率+ΔOAS | M2 再加 `δ_oas·ΔOAS` | 补充检验 |
| 含残差（δ≡1） | M2 再加 `1.0×信用利差代理` | **仅用于证伪**，不作检验 |

**第二步：区分两种 δ 用法。** 事件窗检验所用的 δ 一律只用事件窗**之前**的样本（扩展窗 ≥ 40 日）
重新估计，代表「站在事件发生前、用当时估得出的 δ 去预测」——这是压力测试的真实使用姿势。
全样本 δ 作对照，代表报告上那个数本身的传导能力。

**第三步：偏差分解。** 全样本拟合 `r = c_f + δ_f′x + e_f`（`e_f` 即信用利差代理），
事件前 δ 预测 `r̂ = c_p + δ_p′x`，则 `r − r̂ = [(c_f − c_p) + (δ_f − δ_p)′x] + e_f`，
即 **参数差异项 + 信用残差项**，两项在事件窗上累加。

**第四步：事件窗设定。** 主窗为事件日起 3 个交易日（事件日常在收盘后公布，留出反应日），
另出 1 日、5 日对照。85 条事件中 1 条落在非交易日，映射到其后首个交易日。
按 5 日窗计有 **40 对两两重叠**，事件窗**不是独立样本**，故统计只作描述性偏差幅度，不作显著性检验。

**主检验结果**（主口径 · 事件前 δ · 3 日窗，n=85）：

| 统计量 | 数值 |
|---|---:|
| 偏差中位数 / 均值 / 标准差 | +0.0550 / +0.0896 / 0.3852 pp |
| 绝对偏差均值 / 90 分位 / 最大 | 0.2737 / 0.6548 / 1.4991 pp |
| 低估损失的事件占比 | 40%（34/85） |
| 低估时平均低估 / 最大低估 | 0.2301 / 0.7134 pp |
| 偏差 90 分位 ÷ 基准口径 3 日 95% VaR | **1.07** |
| 最大偏差 ÷ 基准口径 3 日 95% VaR | **2.44** |
| 偏差构成：信用残差项占比 | **88.1%**（|23.30| pp vs 参数差异 |3.13| pp） |
| in-sample vs out-of-sample 绝对偏差均值 | 0.2741 vs 0.2737 pp（放大 **1.00 倍**） |

**核心发现（按实际损益方向拆分）**：

| 子样本 | 事件数 | 低估占比 | 平均偏差 | 绝对偏差均值 | 最大低估 | 最大高估 |
|---|---:|---:|---:|---:|---:|---:|
| **实际亏损事件** | 33 | **58%** | **−0.1219 pp** | 0.2016 pp | −0.7134 pp | +0.2295 pp |
| 实际盈利事件 | 52 | 29% | +0.2238 pp | 0.3194 pp | −0.5181 pp | +1.4991 pp |

**偏差的中位数与均值都很小（0.06~0.09pp），单看这两行会得出「传导基本准确」的结论；
但它在亏损侧系统性偏大——实际亏损的 33 个事件窗中 58% 低估了损失，平均低估 0.1219pp。**
正负两侧的抵消掩盖了真实误差量级，而压力测试只关心亏损侧。

两条证据共同指向「**这不是估计噪声，是结构性漏因子**」：
① 偏差 88.1% 来自信用残差项；② 用样本外 δ 预测几乎没有放大误差（1.00 倍），δ 本身估得很稳。

**口径恒等式的确认**：dev(主) 与 dev(次) 的**最大逐值差 = 0.000e+00**。
原因：`r_rmb ≡ r_tr + fx_ret`（两者均可观测），预测端同样以 +1.0 系数加入 `fx_ret`，
汇率项在「实际 − 预测」中**精确对消**。故：汇率的传导不是估计问题而是**口径搬运，不存在传导精度问题**；
两口径的**绝对**传导误差完全相同，等于利率 + 信用部分的误差。有意义的差别只在相对量级——
同一绝对偏差除以次口径更大的风险尺度后，占比降至 0.35（均值）与 0.85（90 分位）：

| 窗口 | 口径 | 绝对偏差均值 | 绝对偏差 90 分位 | 最大偏差 | 均值 ÷ 窗口 VaR | 90 分位 ÷ 窗口 VaR |
|---|---|---:|---:|---:|---:|---:|
| 1 日 | 主 / 次 | 0.1554 | 0.3365 | 1.1595 | 0.44 / 0.35 | 0.95 / 0.76 |
| 3 日 | 主 / 次 | 0.2737 | 0.6548 | 1.4991 | 0.45 / 0.35 | **1.07** / 0.85 |
| 5 日 | 主 / 次 | 0.3571 | 0.8390 | 1.5147 | 0.45 / 0.36 | 1.06 / 0.84 |

（窗口 VaR = HS250 的 1 日 95% VaR × √窗口长度；主口径 0.3544%、次口径 0.4454%）

**偏差与冲击幅度的关系**：偏差与窗口内利率冲击幅度 `|Δ5Y|+|Δ10Y|` 的相关系数为 **+0.151**
（`figures/delta_transmission.png` 中图），即**偏差不随冲击变大而系统性恶化**。
这对压力测试是有利结论：外推到比历史更极端的冲击时，**没有证据表明线性传导会加速失效**。

**补充检验：加入可观测信用因子 ΔOAS 能否收敛偏差。** OAS 序列（FRED `BAMLEMIBHGCRPIOAS`）
仅自 2023-09-06 起可用（749/1273 日），故只能在事件日不早于该日的子样本上做。
为保证金可比，M2 与 M3 一律在**同一子样本**上比较：

| δ 来源 | 窗口 | 子样本 n | M2 绝对偏差均值 | M3 绝对偏差均值 | 变化 |
|---|---|---:|---:|---:|---:|
| 全样本 δ | 1 日 | 42 | 0.1086 | 0.0849 | −21.9% |
| 全样本 δ | 3 日 | 42 | 0.1818 | 0.1287 | −29.2% |
| 全样本 δ | 5 日 | 42 | 0.2385 | 0.1792 | −24.9% |
| 事件前 δ | 1 日 | 38 | 0.1127 | 0.0929 | −17.6% |
| 事件前 δ | 3 日 | 38 | 0.1907 | 0.1264 | −33.7% |
| 事件前 δ | 5 日 | 38 | 0.2542 | 0.1789 | −29.6% |

六个配置**全部收敛**（−17.6% ~ −33.7%），三个窗口长度方向一致，是明确的正向信号。

**但必须同时说明边界**：该子样本起点为 2023-09，**不含 2022 年信用冲击**，
而 2022 年恰是偏差最大的时段（偏差最大的 6 个事件全部落在 2022-03 与 2022-11）。
故只能说明「在较平静的近期样本上加入 ΔOAS 能改善传导」，
**不能外推为「加入 OAS 就能扛住信用危机」**。此外 OAS 与信用残差项的相关系数仅 −0.258，
且该序列 749 日中有 121 日取值为零（16%），作为中资美元债利差的代理并不完美。

**对阶段三的直接含义**：三条可操作结论——① 利率情景用 δ 线性映射可接受，偏差不随冲击恶化；
② **信用情景不能沿用同一套 δ**，信用维度在现行体系里根本没有系数，需另建传导路径；
③ 情景损失须在 δ 估算值之上**预留偏差缓冲**，量级参照对应窗口的 90 分位绝对偏差。

## 八、局限与优化方向

### 8.1 16 条「存疑」日的敏感性（spec §8.1，必做两版）

存疑清单 `results/doubtful_days.csv`（11 ETF / 3 dOAS / 2 FX，均为**市价口径**识别），
按"只标注不改数"政策处理，**仅从评估样本剔除**（VaR 与收益序列一字不动），逐条：

| 口径 | 剔除集合 | 条数 |
|---|---|---|
| 主口径 | 仅 11 条 `ETF_ret_pct` 类 | 11 |
| 次口径 | 11 条 ETF 类 + 2 条 `FX_ret_pct` 类 | 13 |

不剔除 3 条 `dOAS_bp` 类——它们标注的是 OAS 序列异常，未改动 ETF 收益本身，而 VaR 的判定对象是 ETF 收益。

**结果：spec §6 的预注册结论「两版结果相同」未成立**——**15 个配置的违规计数发生变化**
（放宽到全部 16 条存疑日为 24 个）。原预注册的推理缺口是：由"不进窗内尾部 **1%**"推不出"不构成违规"，
而 **95% 口径的尾部宽达 5%**；2025-03-24 在 W=250 窗内升序排第 11/250（约 4.4 分位），
进得了 95% 尾部、进不了 99% 尾部，故只在 95% 上构成违规。

另有 44 条违规记录直接落在存疑清单的 4 个日期上（2024-02-02 [dOAS] ×9、2024-06-07 [dOAS] ×20、
2025-01-21 [FX] ×11、2025-03-24 [ETF] ×4），**其中 dOAS/FX 两类本就不在剔除集内**。逐条 3141.HK 同向性核对：

- **2025-03-24 同向**：9141 −0.3426% vs 3141 −0.3454%，且伴随 5Y/10Y +9bp、OAS −4bp，
  是**真实市场波动**而非数据瑕疵；
- **2025-01-21 同向**，且主口径当日为**正收益**（+0.2349%），违规只存在于次口径（r = −0.5009%，fx = −0.736%），
  是**纯汇率折算损失**——双口径并行的意义所在；
- **2024-02-02 与 2024-06-07 不同向**（3141 分别 +0.0000% 与 +0.8398%，前者疑为陈旧报价），
  按 spec §8.1「结论不以个别存疑日为准」处理，已在违规判定表中标注。

**结论**：剔除存疑日会改变部分配置的**计数**（15 个中 12 个在 95%、3 个在 99%；放宽版 24 个中 17 / 7），
但**不改变任何一条主结论**——**Kupiec 拒绝与否的判定在两版下翻转数均为 0**，
即覆盖率结论对存疑日的处理方式不敏感。这是本项敏感性检验要确立的东西。

### 8.2 其它已知局限

1. **复权/分红边界**：9141.HK 派息记录来自基金官方公告，样本窗内 20/20 期命中并核对；
   但无官方记录的个别除息日仍可能在收益上留痕。若违规日落在疑似除息日，标注区分即可，**不删除、不因单点改写结论**。
2. **CNY/USD 尾 5 交易日**：样本外末端（8/31~9/4）FRED 汇率尚未发布，次口径在该段留空，
   故次口径有效样本为 1018 日而非 1023 日——**两个口径的样本长度不同，横比时须按 §5.3 用公共样本**。
3. **2025-04-10 的 NAV 陈旧报价**：9141 复权 NAV 收益恰为 +0.0000% 而次口径为 −0.4896%，疑似陈旧报价，
   已随存疑机制记录，本次不作为归因对象。
4. **99% 口径整体检验力不足**：这是本报告最需要向下游使用者强调的一条——
   99% 下 LR_ind 实测水平仅 1.3~1.9%，**"未拒绝"不等于"无聚集"**。
5. **危机窗在样本外为空**：spec §7.3 登记的急性危机窗（2022-06-06 ~ 06-22，12 天）**整体落在估计窗内**，
   在 1023 个样本外日中命中 **0 天**，故未建危机段检验表。若后续要覆盖该段，需延展样本或改用更短的估计窗。

### 8.3 优化方向

1. **窗宽自适应**：HS250 在本样本上同时优于 HS500/750（§5.3），但这是**样本相关**的结论；
   可试验波动率加权的混合窗（如按 σ 状态在 250/750 间切换），并在高波动段单独验证。
2. **提高 99% 口径的检验力**：用更长的样本外区间，或改用加权/平滑型检验（如 NYU 的 Berkowitz 变换检验），
   解决 LR_ind 在低违规率下水平严重偏低的问题。
3. **补充尾部深度检验**：目前只有 ES 的点估计，可加入 ES 的显著性与 ES 回归检验（Acerbi-Szekely 型）。
4. **从 VaR 走向 ES**：阶段三压力测试若以 ES 为报告口径，本报告的 `es` 与 `es_ratio` 列可直接作为基线。

## 九、复现方式

```
build_factors_nav.py → build_tr_factors.py → prep_phase2.py
  → var_parametric.py → var_historical.py → var_backtest.py
```

依赖顺序：`var_historical.py` 读 `results/var_parametric.csv` 的 σ 列做滤波，缺该文件会直接报错退出。
检验层在 `code/var_common.py`，与 9/15、9/16 共用同一套违规判定。
随机数固定（`lr_ind_null` 与 `p_ind_mc_cond` 均用固定种子），CSV 一律 `utf-8-sig`。
`var_backtest.py` 内置**硬断言**：把 9/16 已登记的每一个违规计数写死为期望值，不符即中断——
这是防止跨日口径分叉的主要防线。
