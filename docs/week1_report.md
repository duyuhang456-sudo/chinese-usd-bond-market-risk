## 二、两个关键口径决策（请导师知悉 / 拍板）

1. **组合代理定 9141.HK（USD 柜台），不用 3141.HK（HKD 柜台）。** 理由：3141 虽报价更“活”，但混有 ~7.5%/年柜台专属噪声（非美元债真实风险）+ 2022-04-14 坏报价（单日 +5.13%），对因子拆解与日度 VaR 是“信息污染”，比 9141 的“信息缺失”更伤。
2. **风险计量正式输入用「9141.HK 官方 NAV 日度」（D2），不用市价。** 9141 市价 ~63% 交易日零收益（报价陈旧），直接喂日度 VaR 会**低估约 24%**（市价 0.536% vs NAV 0.663%，1 日 99% VaR）。关键时序发现：**官方 NAV 与美股同日估值（lag=0）**，市价滞后 1 日（lag=1）——NAV 的利率剥离 R²=0.67、等效久期 3.72y，信号远干净于市价（0.23 / 1.74y）。**阶段二 VaR 建议直接以 NAV 口径上报**。

## 四、描述性统计结论（一句话版）

- 收益类全部**尖峰厚尾**（超额峰度组合 2.1 / 汇率 5.4），正态假设不成立 → **阶段二 VaR 应做厚尾校验**（历史模拟优先）。
- **信用利差代理左尾最重**（偏度 −1.51、超额峰度 10.5）：利差多小步压缩、偶发骤然走阔，正是信用风险要计量的方向。
- 组合 = 利率(轻微右偏) + 利差(强左偏) 两因子叠加，才得到温和左偏的组合收益——双因子拆解成立。
