## 二、三个关键口径决策

1. **VaR 输入用复权（总收益），不用除权 NAV。** 9141.HK 为派息型、样本窗内 20 次除息，
   除息跳空计入日收益会系统性高估 σ 与 VaR。实测：σ_年化 4.52%→**4.22%**、1 日 99% VaR
   0.663%→**0.619%**（约低 6%）。除权表保留作审计底。
2. **汇率不置零，双口径并行。** 主口径 = USD 本位复权收益（σ_年化 4.223%、99% VaR 0.619%）；
   次口径 = 人民币视角总收益（5.113%、0.749%）。两者不是同一风险的两种说法——
   归因表给汇率贡献 **44.2%** 的方差，且本样本存在**只在次口径出现的违规**
   （2025-01-21：主口径当日为正收益，次口径 −0.5009%，是纯汇率折算损失）。**次口径不替代主口径。**
3. **Christoffersen 独立性检验与 Kupiec 并列出具，且不假设 χ²(1) 可用。** 用蒙特卡洛实测本样本的
   真实水平：95% 口径下 LR_ind 名义 5% 实际 **7~8%**（偏宽松），99% 口径下实际仅 **1.3~1.9%**（保守）。
   故 CSV 并列给出条件蒙特卡洛 p 值 `p_ind_mc_cond`，**报告以它为准**；
   99% 下「不显著」必须读作**检验力不足的弱结论**，不是「证明无聚集」。

## 四、核心结论

1. **本样本上的主要风险是「过度保守」，不是「风险低估」。** M1/M1g 在 95% 上被 Kupiec 拒绝
   （29 / 30 次违规 vs 期望 48），正是 spec §6 预言的「窗口陈旧 → 系统性过宽」的硬证据；HS750 最严重。
2. **复杂化没有换来可验证的增益。** 三条证据：① δ-normal 与 M1 是**代数恒等式**（σ 最大差 4.4e−06），
   不构成独立证据；② Filtered-HS 的违规率（5.69% / 5.43%）与经典 HS（4.92%）差异落在 2SE 内，
   只能说「未观察到改善」，**不能说滤波有害**；③ GARCH 条件化在聚集性上与无条件模型**不可分辨**
   ——这是 99% 下检验力不足（实际水平约 1.6%）的问题，**不是模型优劣的证据**。
3. **可分辨的差异来自窗宽与分布假设，不来自条件化。** 公共 523 日上 HS250 的失败率最接近名义
   （95% 5.35%），HS500/750 系统性过度覆盖。
4. **推荐口径**：日常计量基线用**主口径（USD 复权）+ HS250**（95% 4.30% 与 99% 0.88% 两档都在
   Kupiec 接受区间内）；M1/M1g 作为**保守上界**（须声明其资本成本）；**人民币次口径全程并列披露**。

## 五、遗留问题

1. **99% 口径整体检验力不足**（LR_ind 实测水平仅 1.3~1.9%）——「未拒绝」不等于「无聚集」，
   需更长样本或改用加权/平滑型检验才能提高分辨力。
2. **次口径 GARCH 有 133/1268 次落到 α→0、β→1 边界解**（2022-08 ~ 2023-04，人民币贬值高波动段），
   该段 σ_t 退化为常数。**该段不得作为「条件化在高波动段更优」的证据**（该段 LR 检验几乎不拒绝任何东西）。
3. **高波动段仅 299 天**（对 HS500/FHS 只有 88 天），99% 下期望违规约 3 次，分段结果**只作描述性对比**；
   且分段标志是含当日的 60 日滚动 σ，属**事后同期标记**，不是事前可知信号。
4. **急性危机窗（2022-06-06 ~ 06-22）整体落在估计窗内**，样本外命中 0 天，故未建危机段检验表。
5. **CNY/USD 尾 5 交易日源未发布**，次口径有效样本 1018 日 < 主口径 1023 日——两个口径横比须用公共样本。
6. `M1g-t` 实为「t 似然估 σ + **正态**分位」，**不是 t 分布 VaR**，已在 spec 与结果表中披露。
7. **2025-04-10 的 NAV 疑似陈旧报价**（复权收益恰为 0.0000% 而次口径 −0.4896%），已随存疑机制记录。

## 六、第 3 阶段（压力测试）交接清单

阶段三要做的是「**给定情景 → 组合损失**」的映射。以下是阶段二已备好、可直接消费的参数与索引。

### 6.1 组合因子暴露 δ（`results/factor_exposure.csv`）

由复权主口径全样本同日 OLS 估计，**单位：% 组合收益**。

| 因子 | 暴露 δ | 单位 | 含义 |
|---|---|---|---|
| 利率 Δ5Y | **−0.007714** | % / bp | 5Y 美债收益率上行 1bp → 组合 −0.77bp |
| 利率 Δ10Y | **−0.029303** | % / bp | 10Y 上行 1bp → 组合 −2.93bp |
| 信用利差代理 | **+1.000000** | % / % | 定义为「剔除利率后的残差」ε，系数按构造为 1；ε 与 ΔOAS 负相关（ρ = **−0.267**），即**利差走阔时 ε 下行** |
| 汇率 CNY/USD | 主口径 **0**；次口径 **+1** | % / % | USD 本位下无汇率风险；人民币视角下为**完全暴露** |

等效久期 **3.70 年**（δ_5Y + δ_10Y = −0.0370%/bp），利率剥离 R² **0.757**。
（阶段一交付的除权口径为 3.72 年 / R² 0.668；复权后 R² 提高，因为除息跳空本身与利率无关，属噪声。）

**方差归因**（`results/var_attribution.csv`，压力情景排序用）：

| 成分 | 主口径 | 次口径 |
|---|---|---|
| Δ5Y | 17.4% | 10.0% |
| Δ10Y | 61.7% | 35.7% |
| 利差代理（残差） | 20.8% | 10.1% |
| 汇率 CNY/USD | — | **44.2%** |

→ 主口径情景以**利率（尤其 10Y）**为主导；次口径必须**同时给汇率情景**，否则会漏掉近一半风险来源。
