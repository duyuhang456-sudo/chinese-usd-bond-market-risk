# 异常值识别与事件校验说明（数据清洗② · 9/9）

> 对应需求文档「阶段一 · 数据清洗②：异常值识别 + 事件校验」。
> 政策口径：**只标注、不改数**（用户决策）。最终 clean 数据数值**零改动**。

## 一、方法

对每条「日变化」序列做**多信号滚动 3σ** 识别，任一命中（且过绝对下限护栏）即记为疑似异常候选：

| 信号 | 含义 | 用途 |
|---|---|---|
| `global z` | 相对全样本均值/标准差 | 全区间尺度上的极端值 |
| `roll60 z` | 相对最近 60 个交易日均值/标准差 | regime 相对：捕捉平静期中的突刺 |
| `roll20 z` | 相对最近 20 个交易日 | 更局部的突刺 |
| `pre60 z` | 相对**前 60 日基线**（std 只用到 t-1，不含当日） | 冲击首日波动率尚未抬升时也能抓住 |

绝对下限护栏（避免微噪声误报，即便 z>3 也过滤）：

| 序列 | 口径 | 下限 |
|---|---|---|
| 5Y / 10Y 美债 | 日变化 (bp) | 8 bp |
| 9141.HK | Adj Close 对数收益 (%) | 0.5% |
| CNY/USD (DEXCHUS) | 对数收益 (%) | 0.45% |
| EM IG OAS | 日变化 (bp) | 5 bp |

候选清单：`clean_data/outlier_candidates.csv`（132 条 / 103 个交易日），逐条带命中信号便于回溯。

> 说明：ETF 对齐到美股交易日，港股休市日由清洗填充为≈0% 收益，0% 不被当作异常。

## 三、逐条判定

`clean_data/outlier_judgment.csv`：每条候选与时间线做 **±3 个自然日事件窗口**匹配，得到判定与处理：

- 命中事件 → **真实冲击**，处理 **保留**，附事件名与偏差天数；
- 未命中 → **存疑（无事件支撑）**，处理 **仅标注、不改数**；
- 极少数特殊日（9141 与 HKD 柜台 3141.HK 反向、或量级偏大）在 `special` 列加注复核结论。

## 四、结论与对下游的说明

1. **clean 数据零改动**：按「只标注不改数」决策，`clean_data/*_clean.csv` 与 9/8 版本完全一致；异常核查结论以本判定表引用日期为口径，flag 列语义不变（0 原始 / 1 前值填充 / 2 线性插值）。
2. **已知口径备注**：FRED OAS 指数约 T+1 发布（例：2023-12-13 FOMC 转鸽当日 OAS 指数 +15bp 实为**前一日**走阔），利差事件校验需容忍该滞后；本 repo 因子表中 OAS 保留原发布日、不做回移，使用方需注意。
3. 时间线 2025–2026 段来自公开检索（置信度标注于 `note`），后续压力测试复用前建议再人工核一遍极少数低置信条目。
